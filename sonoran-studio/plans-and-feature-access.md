# Plans and feature access

| Feature              |         Free | Premium |
| -------------------- | -----------: | ------: |
| Core overlay editor  |            ✓ |       ✓ |
| One fallback layout  |            ✓ |       ✓ |
| Additional layouts   |            — |       ✓ |
| Premium themes       | Preview only |       ✓ |
| Custom widget icons  |            — |       ✓ |
| Layout share codes   |            — |       ✓ |
| Smart lighting       |            — |       ✓ |
| Streamer.bot actions |            — |       ✓ |

Premium access can come from a personal Sonoran Studio subscription or from an eligible Sonoran One community while its CAD or Radio context is active.

{% hint style="info" %}
Your fallback layout remains available if premium access changes. Additional layouts stop broadcasting until premium access returns.
{% endhint %}
