# Quickstart

{% stepper %}
{% step %}
### Sign in

Open Sonoran Studio and select **Continue with Sonoran**. Use the same Sonoran account you use with CAD or Radio.
{% endstep %}

{% step %}
### Choose your canvas

Under **Canvas**, select **Horizontal** for a standard 16:9 broadcast or **Vertical** for a portrait stream. You can also enter an exact width and height.

{% hint style="info" %}
Use the same width and height in Studio and your streaming app. A mismatch can make the overlay look square, stretched, or cropped.
{% endhint %}
{% endstep %}

{% step %}
### Choose and position widgets

Turn each widget on or off under **Widgets**. Drag enabled widgets around the canvas and drag the red corner to resize them.
{% endstep %}

{% step %}
### Style the selected widget

Select a widget to edit its colors, opacity, background fade, content alignment, timing, text size, labels, and row order. Changes save automatically after a short delay.
{% endstep %}

{% step %}
### Test live moments

Use **TEST** next to Radio transmission, Panic takeover, and Dispatch notification. Temporary widgets only appear while live data is present or a test is active.
{% endstep %}

{% step %}
### Add the browser source

Select **Setup guide**, choose your streaming app, copy the private overlay URL, and use the exact source size shown. See [Add Studio to your streaming app](add-studio-to-your-streaming-app.md).
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Keep the Studio editor open while configuring your scene. You can test changes without going live.
{% endhint %}
