# Layouts and canvas

Each layout has its own name, canvas dimensions, widget positions, styling, and private browser-source URL.

## Fallback layout

Every account has one fallback layout. It remains available if premium access changes and is the only broadcasting layout on the free tier.

## Create and choose layouts

Premium users can keep up to eight saved layouts. Use separate layouts when you need:

* Landscape and portrait scenes
* Different streaming destinations
* A gameplay layout and a dispatch layout
* Different widget arrangements for different shows

Select a layout card before editing. The active layout's private URL appears under **Browser source**.

## Canvas size

Choose **Horizontal** for 1920 × 1080, **Vertical** for 1080 × 1920, or enter an exact width and height.

{% hint style="warning" %}
The streaming app's browser-source dimensions must exactly match the Studio canvas. Changing a layout's dimensions does not automatically resize the source in OBS, TikTok LIVE Studio, or Streamlabs.
{% endhint %}

## Replace a browser-source URL

Use **Replace URL** if a URL is exposed or should no longer work. Then copy the new URL into every scene using that layout. The old URL stops loading the overlay.
